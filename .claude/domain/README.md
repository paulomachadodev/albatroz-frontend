# domain/ — Conhecimento de Negócio (Frontend)

Documentação de **domínio de negócio puro**: conceitos, entidades, regras e fluxos do ERP Albatroz vistos pelo frontend. Escrito para humanos e para guiar a IA na geração de componentes, formulários e fluxos de UI.

**Regra de ouro:** zero código aqui. Sem TypeScript, sem HTML, sem nomes de arquivo ou componente de implementação. Se você sentir vontade de escrever `interface`, `@Component` ou `<div>`, o conteúdo pertence a `skills/` ou `standards/`, não aqui.
