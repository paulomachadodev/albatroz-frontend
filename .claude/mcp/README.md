# MCP Servers — Albatroz Frontend

Servidores MCP configurados. Use sob demanda.

## claude_ai_Figma
Design system e prototipagem via Figma. Ler designs (get_design_context, get_screenshot), escrever designs (use_figma), sincronizar código com Figma (Code Connect). Use ao criar telas a partir de designs Figma ou ao sincronizar componentes DS com o arquivo Figma do ERP. Ver @skills/ds-tokens, @skills/create-ds-page e @agents/ds-engineer.

## ide (mcp__ide__)
Diagnósticos e execução de código no editor. `getDiagnostics` retorna erros TypeScript/ESLint do arquivo aberto. `executeCode` roda snippets. Use ao depurar erros de compilação ou verificar diagnósticos antes de editar. Ver @standards/angular/conventions.md.
