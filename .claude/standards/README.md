# Standards — Albatroz Frontend

Regras e convenções de código. Fonte de verdade para geração e revisão.

## Arquivos

| Arquivo | Conteúdo |
|---|---|
| `angular/conventions.md` | Naming, estrutura de módulos, imports absolutos |
| `angular/signals.md` | State management com Signals (input, output, computed, effect) |
| `angular/routing.md` | Rotas, lazy loading, guards, params como Signals |
| `angular/http.md` | HTTP Services, Observable, tipagem, error handling |
| `angular/forms.md` | Reactive Forms, validação, submissão |
| `angular/listagem-padrao.md` | Listagem paginada (`app-listagem-paginada`), drawer (`app-drawer`), autosave por campo |

## Relação com Skills

Standards = **regras** (o quê e por quê).  
Skills = **exemplos** (como implementar).

Para gerar código: use skills.  
Para revisar ou auditar: use standards.
